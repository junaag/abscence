# ABSENCE

Branche de refactor technique **v0.2.0-dev**.

La version jouable v0.1.11 reste sur `main`. Cette branche remplace l'architecture de hotfixs runtime par une source TypeScript lisible, testée et construite avec Vite.

## Développement

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run test:e2e
```

Voir `docs/ARCHITECTURE.md` et `docs/PARITY.md`.
